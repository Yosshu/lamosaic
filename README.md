# lamosaic

写真の顔を、クレヨン風のストロークでおしゃれに隠すWebアプリです。
周りの肌や髪の色を拾って塗るので、写真の雰囲気を壊さずに顔を隠せます。

- PC・iPhone・iPad のブラウザで動きます（ホーム画面に追加すればオフラインでも使えます）
- 画像の処理はすべて端末の中で行い、どこにも送信しません
- 保存した画像からは位置情報などのメタデータが取り除かれます

## できること

- **4種類のブラシ**：クレヨン（粒の粗い帯）・ふんわり（淡い筋）・パステル（乾いたかすれ）・まだら（雲のような模様）。途中で切り替えて混ぜられます
- **色の自動選択**：塗り始めた所の色を拾い、少し明るく・くすませて塗ります。スポイトで色を選ぶこともできます
- **調整**：サイズ・濃さ・粒・くすみ・明るさ、直線モード
- **透けチェック**：重ね塗りが足りず写真が透けている所を表示します
- **おまかせ下塗り**：端末内の顔検出で、目元または顔全体をまとめて下塗りします
- **操作**：取り消し・やり直し、拡大・移動、押している間だけ元の写真を表示

## 操作

| 端末                | 塗る             | 拡大・移動                   | 取り消し              |
| ------------------- | ---------------- | ---------------------------- | --------------------- |
| iPhone / iPad       | 指               | 2本指でピンチ・ドラッグ      | 2本指ですばやくタップ |
| iPad + Apple Pencil | ペン（筆圧対応） | 指                           | 2本指ですばやくタップ |
| PC                  | マウス・ペンタブ | ホイール、スペース＋ドラッグ | ⌘/Ctrl+Z              |

PC のショートカット：`[` `]` サイズ、`1`〜`4` ブラシの種類、`0` 全体表示、`L` 直線、`I` スポイト、`C` 透けチェック、⌘/Ctrl+S 保存。

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト（Vitest）
npm run e2e        # 画面テスト（Playwright）
npm run lint       # ESLint
npm run typecheck  # 型チェック
```

ブラシの質感は `lab.html`（開発サーバーで `/lab.html`）で、全パラメータをスライダーで調整できます。
調整した値は JSON でコピーして `src/brush/presets.ts` に反映します。

### 構成

```
src/
  brush/   ブラシエンジン（帯の形・紙の粒・色の拾い方）、プリセット
  canvas/  レイヤー、取り消し履歴、表示（拡大・移動）、透けチェック
  input/   ポインター入力、軌跡の補間、ジェスチャーの振り分け
  io/      画像の読み込みと保存
  face/    顔検出とおまかせ下塗り
  ui/      プリセットの見本画像
```

## 公開
